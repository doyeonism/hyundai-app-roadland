## release APK

대상: `apk/조도연_Roadland_release.apk`. Pleos Connect v2.1.0, Android 14/API 34, x86_64 보조 에뮬레이터의 새 계정에서 확인했습니다. 기존 주 기기의 앱·데이터는 변경하지 않았습니다.

최초 제출 파일은 설치 후 AndroidX Startup 초기화 중 Kotlin collection 클래스 접근 오류로 종료됐습니다. 부분 패키지 최적화를 해제하고 동일한 release 키로 다시 서명해 해결했습니다. release 변형과 debuggable 비활성은 유지합니다.
