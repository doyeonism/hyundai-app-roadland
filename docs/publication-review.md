## 파일과 Git 이력

| 항목 | 확인 결과 |
|---|---|
| `.env`, `.env.*`, `local.properties`, Mapbox 로컬 토큰 설정 | 추적 파일·과거 파일 경로에서 발견되지 않음. ignore 적용 |
| 개인 키·GitHub/Mapbox/AWS/Google API 키·DB 비밀번호 포함 URL | 검사한 형식의 일치 항목 없음 |
| 서명 키·keystore·인증서 내보내기 | 추적 이력에서 발견되지 않음. `.jks`, `.keystore`, `.pem`, `.key`, `.p12`, `.pfx` 등 ignore 적용 |
| 배포 VM IP | 공개 IPv4 주소가 파일 내용에서 발견되지 않음. 개발용 loopback·에뮬레이터 주소와 구분 |
| APK·영상·신청서·공개키 복사본·진단 자료 | `/output/`, `/.task/` 및 바이너리 패턴으로 제외 |
| API 서버 도메인·타일 URL | 공개 앱 설정으로 남김. 인증용 비밀정보와 구분 |

검사는 파일명과 알려진 비밀정보 형식에 기반합니다. 임의 형식의 비밀번호·의도적으로 숨긴 값·외부 GitHub 캐시·다른 저장소까지 모두 안전하다고 보증하는 결과는 아닙니다. 이미 노출된 비밀정보를 발견하면 이력 제거보다 먼저 해당 자격증명을 폐기·교체해야 합니다.

## 배포·라이선스 확인 사항

- 서버 저장소는 소유자가 확인한 `https://github.com/doyeonism/hyundai-app-roadland-server`로 반영했습니다. 비공개 저장소라면 제출 대상자의 열람 권한을 확인해야 합니다.
- 2026-11-15 별도 키로 서명한 release APK를 `apk/조도연_Roadland_release.apk`에 제공합니다. 이 경로의 `*_release.apk`만 Git 제외 규칙의 예외이며, 나머지 APK·서명 키·비밀번호는 계속 제외합니다. 빌드와 서명 검증 정보는 [APK 안내](../apk/README.md)에 있습니다. GitHub Release 게시와는 별개입니다.

- Pleos SDK·AIDL·데이터·보안 구성요소 12개 좌표는 배포 POM에 라이선스 표기가 없어 별도 공급자 약관 확인 대상으로 남겼습니다. Mapbox 3.x도 일반 MIT/BSD 오픈소스로 분류하지 않았습니다.

- 앱 배포 시 포함된 의존성의 고지문·라이선스 본문 유지 등은 실제 배포물 기준으로 추가 확인해야 합니다. CSV는 버전·출처 목록이며 모든 배포 고지 의무의 이행을 대체하지 않습니다.
